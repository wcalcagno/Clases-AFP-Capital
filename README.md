# Clases AFP Capital

Repositorio público con recursos prácticos utilizados en sesiones de formación técnica sobre análisis de datos, ingeniería de datos y analítica moderna.

Este espacio reúne notebooks, datasets de ejemplo y material complementario utilizados para ejercicios aplicados en entornos de trabajo con Microsoft Fabric, Power BI, SQL y procesos de ingesta de datos.

---

## Objetivo

El propósito de este repositorio es centralizar los recursos utilizados durante las clases, permitiendo que los participantes puedan:

- Replicar ejercicios vistos en sesión
- Explorar notebooks de ejemplo
- Practicar procesos de ingesta y transformación
- Trabajar con datasets reales de laboratorio
- Reforzar conceptos de analítica e integración de datos

---

## Contenido del repositorio

### Notebooks

#### `Fabric_Ingesta_Github.ipynb`
Ejemplo práctico de ingesta de datos desde GitHub utilizando Microsoft Fabric.

Conceptos abordados:

- Conexión a fuentes externas
- Extracción de archivos
- Procesamiento inicial
- Preparación para análisis

---

#### `Colab_Demo_AFP_Capital_Banco_Central.ipynb`
Notebook demostrativo orientado al análisis y exploración de datos en Google Colab.

Incluye:

- Carga de datasets
- Exploración inicial
- Transformaciones
- Visualización básica

---

### Datasets

#### `orders_historico.csv`
Dataset histórico utilizado para ejercicios analíticos.

#### `ventas_tienda.csv`
Dataset de ventas para análisis descriptivo y construcción de métricas.

---

### Material complementario

#### `Sesion5_Power_BI_SQL.pdf`
Material de apoyo correspondiente a la sesión de Power BI y SQL.

---

## Requisitos

Para trabajar con estos recursos se recomienda contar con:

- Cuenta Microsoft Fabric
- Power BI Desktop
- Python 3.10+
- Google Colab (opcional)
- Conocimientos básicos de SQL
- Familiaridad con notebooks Jupyter

---

## Uso recomendado

Se sugiere seguir este orden:

1. Revisar el material PDF
2. Explorar los datasets
3. Ejecutar notebooks paso a paso
4. Adaptar los ejemplos a nuevos escenarios
5. Experimentar con transformaciones adicionales
